# Phân tích và Dự đoán Hiệu quả Thuốc 💊

Dự án Machine Learning này tập trung vào việc phân tích dữ liệu y tế và xây dựng mô hình dự đoán hiệu quả của thuốc (Drug Effectiveness) dựa trên các chỉ số của bệnh nhân.

## 📂 Cấu trúc Dự án

Dự án bao gồm các thành phần chính sau:

* **`Data/`**: Thư mục chứa các bộ dữ liệu (dataset) được sử dụng để huấn luyện và kiểm thử mô hình.
* **`Phân_tích_và_dự_đoán_hiệu_quả_thuốc.ipynb`**: File Jupyter Notebook chính. File này chứa toàn bộ quy trình từ:
    * Khám phá và tiền xử lý dữ liệu (EDA & Preprocessing).
    * Trực quan hóa dữ liệu.
    * Xây dựng và huấn luyện các mô hình Machine Learning.
    * Đánh giá độ chính xác của mô hình.

## 🚀 Yêu cầu Hệ thống & Cài đặt
